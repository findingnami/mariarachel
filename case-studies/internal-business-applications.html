Case Study

Internal Business Applications

Designed and built four internal applications (commission tracking, project management, CRM, and a vendor marketplace) with access and workflow safeguards built in.

Application controls
Context
Four internal business applications
Tools

Operations Intelligence Manager

Overview

I designed and developed four internal business applications for a technology advisory firm: commission tracking, project management, CRM, and a vendor marketplace platform. They are built with Supabase and Vercel, and I use GitHub for version control.

Risk & objective

Manual spreadsheet workflows are hard to control. There are no limits on who can see or change data, no change history, and no consistent way to check calculations or payment status. The objective was to move these workflows into applications that have the controls built in.

Approach

  1. Understand the workflow. Gather requirements from the people who do the work, and identify where manual steps cause errors or lack visibility.
  2. Design the application. Define the data, the roles, and the approvals that the workflow needs.
  3. Build on Supabase and Vercel. Develop the application with a database behind it and deploy it to the web.
  4. Build in controls. Add role-based access, approval workflows, activity logs, two-factor authentication, and data restrictions.
  5. Manage change. Keep the code in GitHub so that changes are tracked and can be reviewed.
  6. Review and improve. Review access and activity across the applications and adjust as the workflows change.

Result

Four internal business applications with access and workflow controls built in, including a commission tracking system that replaces manual spreadsheet workflows.

Through an audit lens

IS auditors assess how applications are designed, how they restrict access, how data is processed, and how changes are made. Having built these systems, I understand the choices behind each of those areas and where weaknesses usually appear. That helps me ask better questions and recognize good answers.
