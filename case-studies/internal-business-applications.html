Case Study

Internal Business Applications

Designed and built four internal applications (commission tracking, project management, CRM, and a vendor marketplace) with access and workflow safeguards built in.

Focus area
Application design and built-in controls
Context
Four internal business applications at a technology advisory firm
Tools
Supabase · Vercel · GitHub
Role
Operations Intelligence Manager

Overview

I designed and developed four internal business applications for a technology advisory firm: commission tracking, project management, CRM, and a vendor marketplace platform. They are built with Supabase and Vercel, and I used GitHub for version control.

Risk & objective

Manual spreadsheet workflows are hard to control. They have no access limits, no change history, and no consistent way to check calculations or payment status. The objective was to move these workflows into applications that have the controls built in.

What I did

  • Designed and built the commission tracking system to automate commission tracking, variance calculations, and payment status monitoring across contracts, clients, and vendors, replacing manual spreadsheet workflows.
  • Built a project management application, a CRM, and a vendor marketplace platform.
  • Built the applications on Supabase and Vercel.
  • Implemented role-based access, approval workflows, activity logs, two-factor authentication, and data restrictions across the applications.
  • Used GitHub version control to track changes to the code.

Controls in place

  • Role-based access
  • Approval workflows
  • Activity logs
  • Two-factor authentication
  • Data restrictions
  • Version control

Result

Four internal business applications with access and workflow controls built in, including a commission tracking system that replaces manual spreadsheet workflows.

What this shows

I understand how business systems are designed, built, deployed, and changed, and I build controls into them. This is the knowledge IS auditors use when assessing application controls and change management.
